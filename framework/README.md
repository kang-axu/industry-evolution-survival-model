# IESM Framework

IESM is the pre-transformation analysis branch of the Industry Transformation Engine (ITE). Its role is to assess how an industry changes before ITE defines an intervention strategy.

## Core Flow

> Historical transition cases → survival branches → value migration → control-point migration → reusable patterns → current-industry assessment → ITE intervention strategy

This flow is frozen for IESM V0.1 as the organizing sequence for the research. It does not yet assert specific causal conclusions or predictive rules.
